## [Unreleased]

### Features

- Initial implementation of pCloud Backup integration
- Digest authentication support (due to OAuth2 portal unavailability)
- Automatic backup upload, list, download, and delete
- Retention policies (count-based and age-based)
- Monitoring sensors for backup status
- Region support (EU/US datacenters)
- Automatic token expiration handling
